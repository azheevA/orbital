# Planet texture assets

Run `npm run assets:download` to download the 2K equirectangular maps used by the 3D scene.

The files are supplied by [Solar System Scope](https://www.solarsystemscope.com/textures/) under **Creative Commons Attribution 4.0 International (CC BY 4.0)**. The maps are based on NASA elevation and imagery data, but are processed and color-tuned by Solar System Scope; they are not official NASA products. Some unmapped areas may be filled with representative terrain.

Attribution: **Solar System Scope — https://www.solarsystemscope.com/textures/**, CC BY 4.0.

The application includes material-color fallbacks if a texture file has not yet been downloaded.
